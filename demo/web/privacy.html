샘플로 편하게 둘러보세요.

이 데모는 가상의 한빛 찬양팀과 샘플 일정으로 구성되어 있습니다. 개인 대화, 연락처, 원본 악보나 사진은 포함하지 않습니다. 곡 제목과 공개 참고 영상 링크를 활용하며, 악보는 시연을 위해 만든 예시입니다.

변경한 내용과 업로드한 파일은 현재 브라우저에만 저장됩니다. 운영 서비스의 데이터베이스로 전송하지 않습니다. 상단의 ‘초기화’를 누르면 샘플로 돌아가며, 다음 날 다시 열거나 데모 데이터가 갱신될 때에도 초기화됩니다.

실제 팀원을 초대하거나 여러 기기 사이에서 데이터를 공유하는 기능은 이 데모에서 제공하지 않습니다. ‘라이브하기’는 현재 기기에서 화면을 미리 보는 기능입니다. 소개 영상의 두 화면 시연은 별도의 테스트 환경에서 실제 동기화를 촬영했습니다.

참고 영상 썸네일을 불러올 때 YouTube 이미지 서버에 연결됩니다. 공개 영상 링크를 누르면 외부 서비스가 열립니다. 사이트 제공을 위해 Firebase Hosting이 사용되며, 이 데모에는 별도의 분석·광고 추적 코드를 추가하지 않았습니다.
